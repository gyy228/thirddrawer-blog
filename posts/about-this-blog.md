这是「桃之夭夭」，一个自己搭的个人博客。

## 名字的来历

取自《诗经·周南·桃夭》：「桃之夭夭，灼灼其华。」

原诗是贺新婚的，但摘出来看，就是桃花开得很盛的样子。我喜欢这个意象——**不为了什么而开，到了时候就开**。

所以这个站也不打算有个明确的定位。不追热点，不排更新计划，也不对谁负责。想写就写，不想写就让它空着。

## 这里有什么

- **文章** —— 你正在看的这种
- **说说** —— 一两句话的碎片，不值得写成长文的东西
- **选刊** —— 每天自动抓取几个技术站，机器挑五条不错的
- **项目** —— 我自己做的东西
- **照片** —— 随手拍的

## 怎么做的

整个站是**静态导出**的，托管在 GitHub Pages 上：

| 部分 | 用的什么 |
|---|---|
| 框架 | Next.js，导出成纯静态 HTML |
| 样式 | Tailwind，配一层毛玻璃 |
| 部署 | 推送到 main 分支，GitHub Actions 自动构建发布 |
| 写文章 | 平时在网页里写，也可以直接改 Markdown |
| 选刊 | 每天 8 点自动跑，机器选完直接发 |

没有数据库，没有服务器，也没有随时可能挂掉的后端。**只要 GitHub 还在，这个站就在。**

## 关于更新

以前注册过四五个博客，写满三篇的一个也没有。

这次不太一样——不把它当「作品」经营，就当是个自己想说话的地方。所以更新会很随意，可能一周三篇，也可能三个月一篇。

你要是想看新东西，可以订阅 [RSS](/rss.xml)，不用总来刷新。
