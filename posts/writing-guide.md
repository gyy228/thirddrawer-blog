## 头部字段

每篇文章开头用三条横线包起来的那一段，叫 front-matter：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `title` | 是 | 文章标题，不写就用文件名 |
| `date` | 是 | 日期，写成 `2026-10-27` |
| `tags` | 否 | 标签，写法是 `[随笔, 工具]` |
| `summary` | 否 | 摘要，显示在列表页 |
| `cover` | 否 | 封面图地址 |
| `draft` | 否 | 填 `true` 就不会被发布 |

文件名就是网址。`posts/why-third-drawer.md` 对应的地址是 `/posts/why-third-drawer`，所以**文件名尽量别用中文**。

## 代码

行内代码长这样：`npm run dev`。

代码块要标上语言，否则不会高亮：

```ts
export function greet(name: string): string {
  return `你好，${name}`;
}
```
