# 音乐文件放这里

## 怎么加

1. 把音频文件放进这个目录，例如 `song.mp3`
2. 打开 `siteConfig.ts`，改 `music` 这一段：

```ts
music: {
  title: "音乐",
  song: "歌名",
  artist: "歌手",
  src: `${BASE_PATH}/music/song.mp3`,   // ← 注意要带 BASE_PATH 前缀
},
```

改完提交推送，约一分钟上线。

## 要求

| 项 | 建议 |
|---|---|
| 格式 | mp3 最稳（所有浏览器都认）；m4a、ogg 也行 |
| 码率 | 128–192 kbps 够用，听感差别不大但体积差一倍 |
| 体积 | **最好控制在 5 MB 以内** |
| 时长 | 当作背景音乐的话，30–60 秒的循环比整首歌更合适 |

> 播放器设了 `preload="none"`，没人点播放就不会下载。但文件本身会随站点仓库一起托管，
> GitHub 仓库建议长期保持在 1 GB 以内，所以别放整张专辑。

## 版权

**只放你有权公开分发的音频**：自己录的、明确标注可商用/CC0 的、或者你自己买的授权。

把商业唱片（比如各大平台的付费曲目）放进公开仓库，等于未经授权在公开网站分发录音制品。
站点托管在 GitHub Pages，收到版权投诉会下架整个仓库——不是删掉那一个文件，是整个仓库。
